# Run 2026-07-29 against a REAL hazed archive produced by ghostd v1.10.16 (-hazemode=hazed,
# -stopatheight=1000, mainnet). 1,255 stripped blocks in gsb00000.dat.
#
# This closes the gap left by prover/evidence/hazed_chain_binding.txt, which used bitcoind-derived
# txids as a stand-in. These txids come from the hazed archive itself — the only copy that exists
# on a hazed node, with witnesses and scriptSigs permanently destroyed.
#
# TWO THINGS THE FORMAT REQUIRED, neither documented outside the code:
#   1. block files are XOR-obfuscated with blocks/xor.dat (here 88a020f371f05420). Not encryption
#      and no security weight, but nothing parses without undoing it. It is also why ghost#542's
#      crash reported magic 'f0542088' — that is the key showing through unwritten zeros, not
#      corruption.
#   2. records are NOT contiguous: files are preallocated, so the archive opens with unwritten
#      space. The parser scans for the GSB magic rather than assuming a packed sequence, so it
#      does not depend on the block index for positions.
#
# Stored txids are not taken on trust: the merkle root is recomputed from whatever txids the
# block yields and must match the header, so a forged stored txid fails.
